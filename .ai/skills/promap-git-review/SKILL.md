# ProMap Cargo — Git Review

Before commit:
1. `git status`
2. inspect diff
3. ensure secrets/generated map data are ignored
4. ensure no accidental `bin/`, `obj/`, `/maps`, `/data`, `*.osm.pbf`, `*.osrm*`
5. build/tests
6. summarize changed files and runtime impact

Keep commits focused and do not rewrite unrelated working changes.
