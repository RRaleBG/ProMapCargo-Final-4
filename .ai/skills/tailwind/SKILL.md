# ProMap Cargo - Tailwind CSS Skill

## UI philosophy

ProMap Cargo is a professional truck navigation application.

Design:

- dark
- mobile-first
- high information density
- touch friendly
- professional navigation UI
- clear hierarchy
- minimal visual noise

## Rules

Prefer existing project classes and components.

Do not randomly introduce a second design system.

Avoid unnecessary inline styles.

Use responsive Tailwind utilities.

Navigation screens must prioritize:

1. Current maneuver
2. Street name
3. Distance
4. ETA
5. Route status
6. Map
7. Secondary controls

Truck controls should remain easy to access on desktop and mobile.

When modifying Tailwind:

1. Search existing classes.
2. Search existing components.
3. Preserve responsive behavior.
4. Check dark mode.
5. Check mobile layout.
6. Avoid duplicate utility combinations.
7. Keep accessibility in mind.
